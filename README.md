# Task 2 - Data Analyst Internship

## Objective
To create meaningful data visualizations that convey business insights using sales data.

## Tool Used
- Microsoft Power BI

## Dataset
- Superstore Sales Dataset

## Dashboard Analysis

The dashboard provides insights into:

- Total Sales
- Total Profit
- Sales performance by Sub-Category
- Quantity by Region
- Customer-wise Sales, Cost and Profit
- Category and Sub-Category analysis by Country
- Regional sales distribution
- Ship Mode analysis

## Key Features

- Interactive Date Filter
- Ship Mode Filter
- KPI Cards for Sales and Profit
- Bar Charts
- Pie Chart
- Map Visualization
- Customer Sales Table

## Dashboard Preview

The dashboard screenshot is included in this repository.

## Conclusion

The Power BI dashboard helps analyze company sales performance and provides insights into sales, profit, customers, regions, and product sub-categories.
